# Coding Agent Animations

three.js animations, built by AI coding agents. Open `index.html` in a browser.

| Collection | Style |
|---|---|
| [WoW Forever Classes](wow/) | voxel |
| [WoW Forever Cities](wow-cities/) | tilt-shift |

Each collection is a folder of self-contained HTML files. Art styles and quality bars live in `styles/`, and agent instructions live in `CLAUDE.md`.
